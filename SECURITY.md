# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by contacting the project maintainer.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

Thank you for helping improve the security of this project.
